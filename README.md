# דף קשר לכיתה ג׳1

אתר שבו הורים ממלאים את פרטי הילד/ה ומעלים תמונה, והכול נכנס ישר לדף הקשר של הכיתה.
המחנכת מנהלת את הרשימה ומורידה גרסה סופית כתמונת PNG.

- **מילוי פרטים**: שם פרטי ושם משפחה של הילד/ה, שמות וטלפונים של ההורים ותמונה. לא צריך חשבון.
- **לוח הכיתה**: דף הקשר בעיצוב חבלים ופולארואידים, מסודר לפי א-ב של שם המשפחה.
- **ניהול**: נכנסים בקוד ניהול. אפשר לערוך, למחוק ולהוסיף ילדים, לעדכן את פרטי הכיתה ואת תמונת המחנכת, ולהוריד את הגרסה הסופית.

הנתונים נשמרים בגיליון Google Sheets של המחנכת. האתר עצמו יושב ב־GitHub Pages.

## הקמה (בערך 10 דקות, פעם אחת)

### 1. הגיליון והשרת הקטן
1. פותחים גיליון חדש ב־[Google Sheets](https://sheets.new) ונותנים לו שם, למשל "דף קשר ג1".
2. בתפריט: **Extensions → Apps Script** (או בעברית: **תוספים → Apps Script**).
3. מוחקים את מה שכתוב שם, ומדביקים את כל התוכן של הקובץ [`backend/Code.gs`](backend/Code.gs).
4. בראש הקוד משנים את שתי השורות:
   - `CLASS_CODE` הוא קוד הכיתה שיופיע בלינק להורים. כדאי לבחור משהו שקשה לנחש, באותיות אנגליות ומספרים.
   - `ADMIN_PIN` הוא קוד הניהול. רק את מכירה אותו.
5. שומרים (אייקון הדיסקט), בוחרים למעלה בפונקציה **setup** ולוחצים **Run**. Google יבקש לאשר הרשאות לגיליון. מאשרים.
6. לוחצים **Deploy → New deployment**. ליד "Select type" בוחרים **Web app**.
   - **Execute as**: Me
   - **Who has access**: Anyone
7. לוחצים **Deploy** ומעתיקים את הכתובת **Web app URL** (מסתיימת ב־`/exec`).

### 2. חיבור האתר לגיליון
1. בריפו ב־GitHub פותחים את הקובץ [`config.js`](config.js) ולוחצים על העיפרון (Edit).
2. מדביקים את הכתובת בין המירכאות: `apiUrl: "https://script.google.com/macros/s/.../exec"`.
3. לוחצים **Commit changes**.

### 3. הפעלת האתר
1. בריפו: **Settings → Pages**.
2. תחת **Branch** בוחרים `main` ואת התיקייה `/ (root)`, ולוחצים **Save**.
3. אחרי דקה-שתיים האתר עולה בכתובת `https://sagieori32-png.github.io/dafkesher/`.

### 4. הלינקים
- **להורים**: `https://sagieori32-png.github.io/dafkesher/#k=קוד-הכיתה`
- **למחנכת**: `https://sagieori32-png.github.io/dafkesher/#k=קוד-הכיתה&admin`, ואז מקלידים את קוד הניהול.

בלשונית הניהול יש גם כפתור שמעתיק את הלינק להורים.

## עדכון הקוד ב־Apps Script
כשהקובץ `backend/Code.gs` מתעדכן (למשל כדי לשמור את הרשימה השמית של הכיתה):
1. מעתיקים את כל התוכן החדש של [`backend/Code.gs`](backend/Code.gs) ומדביקים ב־Apps Script במקום הקוד הישן.
2. מחזירים את `CLASS_CODE` ו־`ADMIN_PIN` לערכים שלכם, ושומרים.
3. **Deploy → Manage deployments**, לוחצים על העיפרון, ב־**Version** בוחרים **New version**, ולוחצים **Deploy**.

הכתובת של ה־Web app לא משתנה.

## שאלות נפוצות
- **הורה רוצה לתקן פרטים?** נכנסים שוב מאותו טלפון, והטופס נפתח עם הפרטים שכבר נשמרו. מטלפון אחר המחנכת יכולה לתקן בלשונית הניהול.
- **שני ילדים באותה כיתה?** אחרי השמירה הראשונה לוחצים "למלא עבור ילד/ה נוסף/ת".
- **שיניתי את Code.gs?** צריך **Deploy → Manage deployments → עריכה → New version** כדי שהשינוי ייכנס לתוקף.
- **פרטיות**: את הנתונים אפשר לקרוא רק עם קוד הכיתה. מי שאין לו את הלינק המלא לא רואה כלום. את הגיליון עצמו לא משתפים עם אף אחד.
