# דף קשר לכיתה ג׳1

אפליקציה ליצירת דף קשר לכיתה, בית הספר הממלכתי הנריאטה סאלד, תשפ״ז (2026-2027).

## מה יש בה
- **לוח הכיתה**: דף הקשר בעיצוב חבלים ותמונות פולארואיד, מסודר לפי א-ב של שם המשפחה.
- **הפרטים שלנו**: טופס להורים: שם פרטי ושם משפחה של הילד/ה, שמות וטלפונים של ההורים, והעלאת תמונה.
- **ניהול**: למחנכת בלבד. עריכה, מחיקה והוספה של ילדים, עדכון פרטי הכיתה והמחנכת, והורדת גרסה סופית כקובץ PNG.

## הערה טכנית
הקובץ `index.html` רץ כ־Artifact ב־claude.ai ומשתמש ביכולות של הפלטפורמה (`claude.use("db")`, `user`, `downloads`) לשמירת הנתונים, להרשאות ולהורדת הקובץ.
כשפותחים אותו מחוץ ל־claude.ai (למשל ב־GitHub Pages), הלוח מוצג בלי נתוני הכיתה, ואי אפשר לשמור בו פרטים.
